# Diagnostics and Support


Diagnostics verifies the core, controller, configuration, System Proxy, privileged
component, TUN, routes, DNS, connectivity, automation, and signing state.

Guided Support runs checks relevant to the problem category and offers only allowlisted
repair actions.

You can preview and export a redacted `.velasupport` bundle. Nothing is uploaded
automatically. The default bundle excludes configurations, subscription URLs, credentials,
SSID values, connection destinations, and Keychain data.
