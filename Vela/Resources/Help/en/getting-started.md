# Getting Started


Vela is a native macOS controller for the Mihomo core. It can run in Engine Only,
System Proxy, or TUN mode.

## Before you connect

Vela needs a valid Mihomo YAML configuration. Import a local file or add a subscription.
Subscription credentials are stored in macOS Keychain.

Vela doesn't change your network during onboarding. After validation, choose a mode from
Overview or the menu bar.

## Recommended first setup

1. Add a configuration.
2. Validate it.
3. Start with System Proxy.
4. Run Diagnostics.
5. Enable TUN later if an application ignores System Proxy.

> TUN requires Vela's privileged component. Vela asks for approval only when you choose TUN.
