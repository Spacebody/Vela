# CLI and Shortcuts


This Release Candidate does not advertise a production CLI, App Intents, or a
user-level automation socket.

Those surfaces remain gated until Vela has a production command bus, signed local-peer
authentication, versioned JSON, exit-code, and error contracts, plus update compatibility
tests.

The privileged Helper is not an automation endpoint and does not accept passthrough
commands. Examples from future contract drafts are not available in this build.

Use Vela's interface for status, profile or mode changes, diagnostics, and Help.
