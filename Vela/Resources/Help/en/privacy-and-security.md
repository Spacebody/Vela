# Privacy and Security


Vela is designed to keep operational data local.

- Subscription credentials and configured Wi-Fi names are stored in Keychain.
- Connection snapshots are kept in memory by default.
- Vela doesn't include remote analytics.
- Vela doesn't automatically upload crash reports.
- Help content is bundled with the App.
- Support bundles are created only after your explicit action.

Vela may contact user-configured subscription/provider servers, its signed App update
feed, and its signed core catalog.

Use the private channel in Vela's Security Policy for vulnerabilities. Don't post
credentials or private configurations publicly.
