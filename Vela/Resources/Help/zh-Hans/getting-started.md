# 开始使用


Vela 是一款使用 Mihomo 内核的原生 macOS 网络控制器，可运行于仅启动内核、系统代理或
TUN 模式。

## 连接前

Vela 需要一份有效的 Mihomo YAML 配置。你可以导入本地文件，也可以添加订阅。订阅凭据
保存在 macOS 钥匙串中。

引导过程中，Vela 不会更改系统网络。配置校验通过后，可在“总览”或菜单栏中选择网络模式。

## 推荐的首次设置

1. 添加配置。
2. 校验配置。
3. 先使用系统代理。
4. 运行诊断。
5. 如果某些应用不遵循系统代理，再启用 TUN。

> TUN 需要 Vela 特权组件。只有在你明确选择 TUN 时，Vela 才会请求授权。
