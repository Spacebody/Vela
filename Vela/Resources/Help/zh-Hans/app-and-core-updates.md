# 应用与内核更新


Vela 应用更新使用 Sparkle 签名归档、签名 Appcast、Developer ID 和 Apple 公证。安装前，
Vela 会安全停止 TUN 并记录恢复事务。

Mihomo 内核更新使用独立的签名目录。Vela 内置的内核始终保留在应用中，运行时不会被替换。

候选内核启用后会进入观察期。如果出现与内核相关的健康问题，Vela 会回滚到上一份已验证内核
或内置内核。

## 已知限制

此 RC 声明以下非停止发布级限制：

- Vela V1 仅支持 arm64 Apple Silicon Mac，不提供 Intel 或 Universal 二进制文件。
- Vela V1 要求 macOS 15 或更高版本。
- TUN 与其他正在运行的 VPN 可能争用路由或 DNS。启用 Vela TUN 前请停止其他 VPN，
  或改用系统代理模式。
- 订阅可以提供 Mihomo YAML、Base64 编码的 YAML，或支持的明文/Base64 代理链接列表。
  真正的 HTML 页面、格式错误或不受支持的内容会被拒绝。
- Vela 不会在较新的数据架构上静默安装旧版应用。手动降级前，请遵循已记录的备份、导出、
  最近一次可用的官方安装包与恢复流程。
- V1 发布线中不可变的内置内核固定为 Mihomo v1.19.29。可用时，请使用 Vela 已签名内核
  目录中兼容且未被阻止的内核。
- 此 RC 未启用按 SSID 触发的自动场景。未来通过门禁的实现需要先获得定位权限，macOS 才会
  提供当前 Wi-Fi 名称；当前版本不执行 SSID 匹配。
- 崩溃与支持诊断会保留在本地，只有你明确导出并分享已脱敏支持包时才会离开设备；Vela
  不会自动上传诊断。
- Beta 与 RC 属于预发布软件，可能包含尚未解决的非停止发布级回归。请保留最新备份；如有
  可用，请保留最近的已知良好官方安装程序。关键生产网络请使用稳定版。
