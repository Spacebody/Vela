# Vela 隐私政策

Vela 是一款以本地处理为优先的 macOS 网络控制器。

配置与设置保存在 Application Support。订阅凭据和已配置的 Wi-Fi 名称保存在 macOS
钥匙串中。

Vela 可能访问用户配置的订阅/Provider 服务器、Vela 的签名应用更新 Feed、Vela 的签名
Mihomo 内核目录，以及你明确打开的链接。

Vela 不包含远程使用统计，也不会自动上传崩溃报告。只有在配置按当前 Wi-Fi 名称匹配的场景
时，Vela 才会请求定位权限；Vela 不扫描附近网络，也不读取 BSSID。

只有在你明确操作后，Vela 才会生成并保存支持包，且不会自动上传。

本模板在公开发布前需要产品和必要的法律审阅。
