# Vela Security Policy

Report vulnerabilities through Vela's published private security contact. Don't post
credentials, subscription URLs, private configurations, or exploit details publicly.

The current Stable release receives security fixes. The immediately previous Stable may
receive update or recovery guidance when practical. Beta support is best effort.

Vela uses Developer ID, Apple notarization, signed App updates, a separately signed core
catalog, and authenticated XPC for the privileged component.

Replace this template with a real private contact before publication.
