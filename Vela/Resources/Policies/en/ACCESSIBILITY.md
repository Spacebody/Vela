# Vela Accessibility

Vela is designed for keyboard navigation, VoiceOver, increased contrast, reduced motion,
and light or dark appearance.

The project audits configuration management, System Proxy and TUN controls, tables,
inspectors, the Configuration Workbench, Help, update recovery, and support export.

When reporting an accessibility issue, include the Vela version, macOS version, assistive
technology, affected screen, and reproduction steps without private network configurations.
