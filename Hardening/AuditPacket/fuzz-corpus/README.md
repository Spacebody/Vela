# Synthetic fuzz-corpus policy

Fuzz inputs must be synthetic and non-secret. Target bounded XPC DTO/JSON shape, YAML
depth/alias/size, Automation framing only if a production protocol is later implemented,
Core/App catalog envelopes, Help markup/links/bidi, and Support ZIP/redaction. Record the
generator version and corpus hash. Never seed from a user's profile, subscription, node,
SSID, log, support bundle, or Keychain item.
