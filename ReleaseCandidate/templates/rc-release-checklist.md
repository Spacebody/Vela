# Vela RC release checklist

- [ ] Clean exact signed tag and monotonic build
- [ ] Feature and Public Contract Freeze clean
- [ ] V0.1 through V0.8 migration evidence passed
- [ ] Critical/High audit findings verified or formally out of scope
- [ ] 72-hour soak and performance/energy gates passed
- [ ] Accessibility, localization, privacy, support, and incident gates passed
- [ ] Install, upgrade, TUN, Core, Helper, CLI, repair and uninstall matrix passed
- [ ] Developer ID App and DMG signed, notarized and stapled
- [ ] Appcast/archive/notes signed; manifests, SBOM and checksums agree
- [ ] Public artifact set contains only the verified audit summary; private closure retained outside public output
- [ ] dSYM/xcarchive and notary receipts privately retained
- [ ] Known Limitations and Previous Stable reviewed
- [ ] No S0/S1, unknown, missing evidence, or Stop-Ship
- [ ] Go/No-Go approvals bind the exact candidate version, build, commit, and artifact SHA-256
